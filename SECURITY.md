# Security Policy

## Versiones soportadas
Este repositorio mantiene soporte activo en la rama `1.21-latin`.

## Reportar vulnerabilidades
No abras vulnerabilidades en issues públicos.

1. Abre un advisory privado o contacta a administradores de SlimefunNewHorizons.
2. Incluye versión, impacto y pasos de reproducción.
3. Adjunta stacktrace/superficie afectada si existe.

Se intentará confirmar recepción en 72h.
